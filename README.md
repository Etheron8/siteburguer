# siteburguer

Landing page one page de delivery de lanches com imagens, cardápio, filtros e carrinho.

## O que esta versão inclui

- Landing page responsiva para delivery de hambúrgueres e acompanhamentos.
- Cardápio com quatro produtos de demonstração, preços e imagens externas.
- Filtro por categoria.
- Carrinho interativo com quantidade, total e opção de limpar.
- Testes DOM que exercitam a página e suas interações.

## Executar localmente

```bash
npm install
npm test
```

Abra `index.html` no navegador para visualizar a página.

## Antes de receber pedidos reais

Os produtos e preços são exemplos. Revise o conteúdo e os direitos/URLs das imagens antes de publicar. Para encaminhar pedidos ao WhatsApp, configure `WHATSAPP_NUMBER` em `script.js` com o código do país e o número da loja, somente dígitos. Até esse número ser configurado, o checkout informa que o pedido foi montado, mas não o envia.

As imagens de produto são carregadas de URLs do Unsplash e precisam de internet para aparecer.
